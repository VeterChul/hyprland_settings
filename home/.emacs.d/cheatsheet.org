#+TITLE: Шпаргалка Emacs

* Вкладки (tab-bar)
- C-S-t               — создать новую вкладку и выбрать проект
- C-<tab>             — переключиться на следующую вкладку
- C-S-<iso-lefttab>   — переключиться на предыдущую вкладку
- C-1 … C-9, C-0      — переключиться на вкладку по номеру (0 = 10)
- C-S-q               — закрыть текущую вкладку (если вкладки включены)

* Навигация между окнами
- C-h / C-l / C-j / C-k        — перемещение между окнами (windmove)
- C-S-h / C-S-l / C-S-j / C-S-k — перемещение буферов между окнами (buf-move)

* Терминал (vterm)
- C-<return>           — открыть терминал снизу (горизонтальный сплит)
- C-S-<return>         — открыть терминал справа (вертикальный сплит)
- C-c o                — открыть OpenCode для текущего проекта
  - C-u C-c o          — перезапустить сессию OpenCode
- В терминале:
  - ESC (или C-c C-c) — войти в режим копирования (все бинды Emacs)
  - q                 — выйти из режима копирования
  - C-S-c             — копировать выделенное
  - C-S-v             — вставить из буфера обмена

* Файловый менеджер (dired-sidebar)
- C-e                 — показать/скрыть панель
- В панели:
  - j / k             — навигация по файлам
  - l / h             — открыть файл/папку (умное окно)
  - TAB               — развернуть/свернуть папку
  - N                 — создать новый файл
  - a / +             — создать папку
  - D                 — пометить файл на удаление
  - x                 — удалить помеченные
  - R                 — переименовать файл
  - C                 — копировать файл
  - m                 — пометить файл (для операций)
  - u                 — снять пометку с текущего
  - U                 — снять все пометки
  - o                 — открыть файл в вертикальном сплите (справа)
  - O                 — открыть файл в горизонтальном сплите (снизу)
  - y                 — скопировать полный путь файла в буфер обмена
  - t                 — открыть терминал в текущей папке
  - ~                 — перейти в домашнюю папку
  - ^                 — перейти в корень проекта
  - /                 — перейти в корень файловой системы
  - s                 — поиск по имени (помечает файлы)
  - .                 — показать/скрыть скрытые файлы (точка-файлы)
  - g                 — обновить список файлов
  - ?                 — справка по dired

* Проекты (Projectile)
- C-S-n               — выбрать проект (переключиться)
- C-S-p               — добавить известный проект
- При старте Emacs автоматически открывается выбор проекта (после подсказки)

* Гидры (быстрые настройки)
- C-c s               — открыть гидру настроек:
  - n — переключить номера строк
  - r — переключить относительные/абсолютные номера
  - t — следующая тема
  - T — тема my-kitty
  - f — увеличить шрифт
  - s — уменьшить шрифт
  - p — переключить автооткрытие PDF для TeX
  - h — справка по номерам строк
  - q — выйти
- C-S-SPC             — открыть гидру изменения размеров окон:
  - h / l — уменьшить/увеличить ширину
  - j / k — увеличить/уменьшить высоту
  - SPC — сбросить размеры (balance-windows)
  - q — выйти

* Игры
- C-c t               — открыть Тетрис (в сплите или плавающем фрейме)
- C-c p               — открыть Пинг-понг

* Общие команды
- C-x C-c             — выход из Emacs
- C-x C-s             — сохранить текущий файл
- C-x C-f             — открыть файл (find-file)
- C-x b               — переключить буфер
- C-x o               — переключиться на другое окно
- C-s                 — сохранить файл (переопределено, стандартный isearch заменён)
- C-b                 — открыть буфер через consult-buffer
- C-d                 — открыть файл в вертикальном сплите
- C-S-d               — открыть файл в горизонтальном сплите
- C-o                 — найти файл через consult-find и открыть вертикально
- C-S-o               — найти файл через consult-find и открыть горизонтально
- C-q                 — сохранить и закрыть текущий буфер/окно
- C-S-q               — закрыть вкладку (если включена) или убить буфер
- C-S-c               — копировать выделенное в системный буфер
- C-S-v               — вставить из системного буфера
- C-c h               — открыть эту шпаргалку

* Компиляция и запуск
- F5                  — запустить текущий файл; окно компиляции снизу, 1/3 высоты
- S-F5                — то же, но окно справа или снизу автоматически по раскладке
- Поддерживаются: .py, .tex, .c, .cpp, .sh, .go, .rs
- Автоматически перезагружаются буферы после успешной компиляции

* LaTeX
- При открытии .tex файла автоматически открывается соответствующий PDF (если он есть и опция включена)
- В гидре настроек (C-c s) можно переключить автооткрытие PDF (кнопка p)

* Сворачивание кода (origami)
- za               — переключить складку (открыть/закрыть)
- zc               — закрыть складку
- zo               — открыть складку
- zM               — закрыть все складки
- zR               — открыть все складки
- zj / zk          — перейти к следующей / предыдущей складке

* Буфер с подсказками (этот файл)
- C-c h               — открыть этот буфер в любой момент
- q                   — закрыть буфер (если в нём)
