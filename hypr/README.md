## Установка и настройка

В этой главе рассказанно, как установить все что нудно для коректной работы системы

### Установить pac_inst.txt через pacman 

Установка из оффициального репозитория Arch
```
sudo pacman -S --needed $(cat pac_inst.txt)
```


### Установить aur_inst.txt через любой пакетный менеджер для AUR

Устновки пакетного менеджера yay:
```
git clone https://aur.archlinux.org/yay.git
cd yay
makepkg -si
```

Установка пакетов из AUR:

```
yay -S --needed $(cat aur_inst.txt)
```

или

```
paru -S --needed $(cat aur_inst.txt)
```


после этого должны были установиться все пакеты, для корекной работы конфигов

### Настрока симлинков

Осторожно, все предыдущие конфиги удаляться!

Для настрокойки всех симлинков(ссылок) надо выполнить скрипт из корневой папки git репозитория(не из ./hypr!!!)|

```
bash hypr/create_symlinks.sh
```

Это удалит все предыдущие конфиги, связаные с приложениеми, настроки для которых представлены в репозитории.

Место этого скрипт создаст симлинки на файлы находящиееся тут, что позволит удобнее за ними следить и обновлять.

### Обои

## Идеология и использование сборки

Тут будет описанно, как задумывалось использование системы и как её пользовать

### Идеология

Система настроенна так, чтобы её можно было и удобно было пользоваться без мыши и полностью себя оправдывает, до появления приложений, которые это не поддерживают. 

Удобно помещать на первом рабочем пространстве все приложения работающие в фоне по типу VPN, музыки, блютуза и тд. 

На втором рабочем пространстве рахзмешать приложение, с которым работаешь и дальше по мере неважности приложений.

Бинды системызаточены под такое использование!!!

### Бинды

Менять в hypr/hyprland.conf 

#### Браузеры и интернет
| Комбинация | Действие |
|------------|----------|
| `WIN + B` | Основной браузер (Zen) |
| `WIN + SHIFT + B` | Второстепенный браузер (Яндекс) |
| `WIN + W` | Выбор Wi-Fi сети |

#### Приложения
| Комбинация | Действие |
|------------|----------|
| `WIN + T` | ferdium |
| `WIN + SHIFT + T` | Telegram |
| `WIN + C` | VSCodium |
| `WIN + Enter` | kitty |
| `WIN + SHIFT + Enter` | cool-retro-term |
| `WIN + CTRL + Enter` | eDEX-UI |

#### Файлы
| Комбинация | Действие |
|------------|----------|
| `WIN + E` | Графический файловый менеджер |
| `WIN + SHIFT + E` | Консольный файловый менеджер |

#### Система
| Комбинация | Действие |
|------------|----------|
| `WIN + SPACE` | Смена языка |
| `WIN + M` | Экран блокировки |
| `WIN + SHIFT + M` | Выйти из Hyprland |

#### Работа с приложениями
| Комбинация | Действие |
|------------|----------|
| `WIN + D` | Rofi (запуск приложения) |
| `WIN + SHIFT + D` | Rofi (переход к запущенному приложению) |
| `WIN + Стрелка` | Сместить фокус |
| `WIN + SHIFT + Стрелка` | Переместить приложение |
| `WIN + CTRL + Стрелка` | Поменять размер прилоожения |
| `WIN + Цифра` | Переместиться на рабочий стол |
| `WIN + SHIFT + Цифра` | Переместить приложение на рабочий стол |
| `WIN + SHIFT + CTRL + Стрелка влево/вправо` | Переместиться на следующий/предыдущий рабочий стол |
| `WIN + SHIFT + CTRL + Стрелка вниз/вверх` | Переместиться на 2/10 рабочий стол |
| `WIN + H` | Переместиться на 2 рабочий стол |
| `WIN + ЛКМ` | Переместить приложение

## Настройка

тут описанно где можно отредактирлвать настроки системы

| Файл | За что отвечает |
|------------|----------|
| `hypr/hyprland.conf` | Бинды, анимации, приложения при старте |
| `hyprlock/hyprlock.conf` | Экран блокировки, при закрытии кришки и CTRL L|
| `kitty/kitty.conf` | Настроки терминала | 
| `mako/config` | Настрока уведомлений |
| `rofy` | Настрока программы для запуска приложения |
|  `waybar` | Настроки панели сверху |
| `.p10k.zsh` | Настроки темы zsh |
| `.zshc` | Настроки zsh |
