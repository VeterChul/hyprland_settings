
# Приветствую в моём Hyprland

## Кратко

Это моя полная конфигурация для оконного менеджера Hyprland. Всё заточено под управление без мыши, с удобной навигацией по рабочим столам, кастомными анимациями, прозрачностью и набором предустановленных приложений. Ниже — установка, настройка и ежедневное использование.

## Идеология

Окружение настроено так, чтобы максимально эффективно работать с клавиатуры. Мышь — опциональна, но не запрещена. Приложения, которые работают в фоне (VPN, музыка, Bluetooth), удобно располагать на первом рабочем столе. На втором — основное рабочее приложение. Далее — по мере убывания важности.

Клавиатурные привязки продуманы именно под такой сценарий: быстрое переключение между рабочими столами, перемещение окон, запуск приложений — всё одной левой рукой на `SUPER`.

## Установка и настройка

Можно запустить быструю установку с помощью
```
cd ~/.myconfig
chmod +x hypr/install.sh
./hypr/install.sh
```

### Установка пакетов

Перейдите в папку `hypr` вашего репозитория. Установите официальные пакеты через `pacman`:

```bash
sudo pacman -S --needed $(cat pac_inst.txt)
```

Затем установите пакеты из AUR (через `yay`, `paru` или другой помощник):

```bash
yay -S --needed $(cat aur_inst.txt)
```

> Файлы `pac_inst.txt` и `aur_inst.txt` содержат полный список зависимостей, включая `hyprland`, `waybar`, `swaybg`, `kitty`, `rofi`, `dolphin`, `yazi`, `codium`, `zen-browser`, `flameshot`, `hyprlock`, `mako`, `brightnessctl`, `playerctl`, `wpctl` и другие.

### Настройка симлинков

Скрипт `create_symlinks.sh` удалит ваши существующие конфигурационные файлы для перечисленных приложений и создаст симлинки на файлы из этого репозитория.

**Внимание:** все ваши предыдущие настройки будут удалены.

Выполните из **корневой папки репозитория** (не из `./hypr/`):

```bash
bash hypr/create_symlinks.sh
```

Симлинки позволят легко обновлять конфигурацию через `git pull`.

### Обои

По умолчанию используется `swaybg` с изображением `night_city.jpg` из папки `hypr/.screenshot/`. Путь прописан в `hypr/hyprland.conf` в строке:

```ini
exec-once = swaybg -i /home/veter/.myconfig/hypr/.screenshot/night_city.jpg

```

Вы можете заменить путь на свой или использовать другой wallpaper-менеджер (например, `hyprpaper`). Соответствующий `exec-once` закомментирован в конфиге.

## Использование

### Базовые возможности

- **Запуск приложений** — через меню `rofi` (`SUPER + D`) или по горячим клавишам.
- **Навигация по окнам** — `SUPER` + стрелки (или `HJKL`).
- **Перемещение окон** — `SUPER + SHIFT` + стрелки (обмен окнами, а не просто перемещение).
- **Изменение размера** — `SUPER + CTRL` + стрелки.
- **Рабочие столы** — 10 столов, переключение `SUPER + [цифра]`, перемещение окна `SUPER + SHIFT + [цифра]`.
- **Скриншоты** — `Print` (область), `SUPER + Print` (весь экран в буфер).
- **Экран блокировки** — `SUPER + M` (вызов `hyprlock`), автоматический блок при закрытии крышки ноутбука.
- **Управление звуком и яркостью** — мультимедийные клавиши (XF86Audio*, XF86MonBrightness*).

### Полный список горячих клавиш

#### Браузеры и интернет
| Комбинация | Действие |
|------------|----------|
| `SUPER + B` | Основной браузер (Zen) |
| `SUPER + SHIFT + B` | Второстепенный браузер (Яндекс.Браузер) |
| `SUPER + W` | Выбор Wi-Fi (nmtui) |

#### Приложения
| Комбинация | Действие |
|------------|----------|
| `SUPER + T` | Ferdium |
| `SUPER + SHIFT + T` | Telegram |
| `SUPER + C` | VSCodium |
| `SUPER + Return` | Kitty |
| `SUPER + SHIFT + Return` | cool-retro-term |
| `SUPER + CTRL + Return` | eDEX-UI |

#### Файловые менеджеры
| Комбинация | Действие |
|------------|----------|
| `SUPER + E` | Dolphin (графический) |
| `SUPER + SHIFT + E` | Yazi (консольный) |

#### Система
| Комбинация | Действие |
|------------|----------|
| `SUPER + SPACE` | Смена раскладки (us/ru) |
| `SUPER + M` | Блокировка экрана |
| `SUPER + SHIFT + M` | Выход из Hyprland |

#### Работа с окнами
| Комбинация | Действие |
|------------|----------|
| `SUPER + Q` | Закрыть активное окно |
| `SUPER + F` | Полноэкранный режим |
| `SUPER + V` | Переключить плавающий режим |
| `SUPER + D` | Rofi (запуск программ) |
| `SUPER + SHIFT + D` | Rofi (переключение между окнами) |
| `SUPER + стрелки` / `HJKL` | Сместить фокус |
| `SUPER + SHIFT + стрелки` / `HJKL` | Обменять окна местами |
| `SUPER + CTRL + стрелки` / `HJKL` | Изменить размер окна |
| `SUPER + ЛКМ` | Переместить окно |
| `SUPER + ПКМ` | Изменить размер окна |

#### Рабочие столы
| Комбинация | Действие |
|------------|----------|
| `SUPER + [1–9,0]` | Переключиться на стол 1–10 |
| `SUPER + SHIFT + [1–9,0]` | Переместить окно на стол 1–10 |
| `SUPER + SHIFT + CTRL + влево/вправо` | Предыдущий/следующий стол |
| `SUPER + SHIFT + CTRL + вверх/вниз` | На стол 10 / на стол 2 |
| `SUPER + H` | Переключиться на 2-й стол (быстрый доступ) |
| `SUPER + мышь (колёсико)` | Пролистывание столов |

#### Мультимедиа
| Комбинация | Действие |
|------------|----------|
| `XF86AudioRaiseVolume` | Увеличить громкость |
| `XF86AudioLowerVolume` | Уменьшить громкость |
| `XF86AudioMute` | Заглушить звук |
| `XF86AudioMicMute` | Заглушить микрофон |
| `XF86MonBrightnessUp` | Увеличить яркость |
| `XF86MonBrightnessDown` | Уменьшить яркость |
| `XF86AudioNext` / `Prev` / `Play` | Управление мультимедиа (через playerctl) |

## Настройка

Все конфигурационные файлы находятся в папке `hypr` и раскладываются симлинками по стандартным путям.

| Файл / папка | Назначение |
|--------------|-------------|
| `hypr/hyprland.conf` | Основной конфиг Hyprland: мониторы, бинды, анимации, автозапуск, правила окон |
| `hyprlock/hyprlock.conf` | Экран блокировки (запуск по `SUPER+M` и закрытию крышки) |
| `kitty/kitty.conf` | Настройки терминала Kitty |
| `mako/config` | Настройки демона уведомлений Mako |
| `rofi/` | Конфигурация запускатора Rofi |
| `waybar/` | Конфиг и стили панели Waybar |

### Важные детали из `hyprland.conf`

- **Рендеринг:** принудительно используется Vulkan (`env = WLR_RENDERER, vulkan`).
- **Анимации:** настроены несколько кривых Безье, отдельные анимации для окон, рабочих столов, затухания.
- **Прозрачность:** по умолчанию выключена (1.0), но в конфиге закомментированы правила для Kitty, VSCodium и eDEX-UI — можно раскомментировать для полупрозрачности.
- **Blur:** включён (размер 3, 1 проход).
- **Тени:** включены.
- **Закругления углов:** 10px.
- **Раскладка:** Dwindle (древо) + псевдотайлинг, сохранение сплитов.
- **Жесты тачпада:** горизонтальное тремя пальцами → смена рабочего стола.

## PS

В сборку включён модифицированный `app.asar` для **eDEX-UI**, в котором вырезаны звуки переключения папок. Если вы тоже хотите тишины:

```bash
sudo cp ~/.myconfig/hypr/eDEX-UI/my_file/edex-ui-mod.asar /opt/edex-ui/resources/app.asar
```

Осторожно: замените путь к исходному файлу, если ваш репозиторий лежит не в `~/.myconfig`.
